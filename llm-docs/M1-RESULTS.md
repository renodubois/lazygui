## Implementation decisions

### Git, targets and partial patches

- Installed Git is authoritative. Readiness enforces 2.56.0; production preserves configured hooks/filters/signing/identity except explicit nonterminal prompt restriction and removal of inherited repository/index selection overrides. Built-ins use direct argv/literal byte paths and no shell interpolation.
- Index/worktree/common-dir resources are coordinated by one startup gate holder. Working-tree leases span verification, dispatch, authoritative read and selection/focus delivery. Commit All lease spans HEAD/status reconciliation. External Git locking/races remain authoritative; GUI gates are not filesystem transactions.
- Canonical raw patches are independent of context/whitespace presentation. IDs are snapshot-scoped, never screen rows. Partial additions/deletions/replacements and reverse multi-hunk subsets preserve actual file semantics and worktree bytes. Complete new/delete selection uses whole-file semantics.
- Binary, symlink/gitlink, rename/copy, mode changes, missing-final-newline and malformed/unknown metadata are explicit partial fallbacks. Regular zero-context hunks and whitespace-ignored display disable partial operations; whole-file actions remain separate. New/delete regular text can safely have context-free hunks. No lossy display patch is applied.
- Reads collect status before/after patches (two traversals for untracked collections, not one per file). Inconsistency reports a refresh error, not a fabricated atomic snapshot.

### Commit policy

- Commit subject must be nonempty/single-line; body NUL-free. Message goes to `git commit --file=- --cleanup=verbatim` stdin, never argv. Configured signoff uses Git's real committer identity via `--signoff`.
- Ordinary hooks execute. `git.skipHookPrefix` uses original subject, nonempty literal case-sensitive prefix, no trimming/word boundary/removal; only then `--no-verify` skips pre-commit/commit-msg (not every hook). Prefix remains in the message.
- No-stage warning requires explicit stage-all confirmation; configured skip stages fresh currently changed paths once. Stage-all, commit and reconciliation share All lease. Failure/cancel never implies no effects or automatic retry. Changed HEAD after an error/unchanged HEAD after apparent success/read failure is uncertain.
- Full raw commit-object messages are length-framed for recall, preserving body/hard breaks/trailers. Non-UTF8/NUL messages stay read-only rather than being converted lossily to editable drafts. Wrap rules use grapheme display cells, preserve hard breaks/whitespace/long words and protected footnote/trailer spaces; subject is not wrapped.
- `git.commitPrefixes` exact repository rules precede global `git.commitPrefix`; first matching nonempty pattern wins even with empty replacement, unmatched branch text survives Go-style ReplaceAllString. Detached matching uses full OID; ordinary linked worktree uses main repository basename. Ambiguous nonstandard linked metadata/non-UTF8 names are diagnosed.
- Prefixes prepare only a fresh empty draft asynchronously under owner revision/generation guards. Edits/recall/cancel win; failed/reopened drafts and explicit retries are not prefixed again. Conservative Go-compatible regex subset: invalid/unsupported constructs (lookaround/backrefs, incompatible flags/classes/Unicode properties, Unicode replacement variable names, unsafe repetition syntax) **transactionally fail**, retaining previous settings. This is not all-Go-regexp or Go-template support.

### Input, refresh and shutdown

- Scoped action definitions power keys/help/click labels. Contextual bindings and contextual universal-name overrides precede universals; labels omit shadowed keys. Editors/popups are exclusive. Marked composition is checked before Kit action dispatch; real physical IME remains a human gate.
- Tree/flat/text/status filters and visible ranges cannot retain hidden write targets. Directory Enter expands/collapses; file Enter opens diff; `0` focuses main, Esc returns; `a` toggles hunk/line, Tab chooses side, `v`/Shift+arrows ranges. Clipboard is display text, never a byte-path operation target.
- Automatic refresh uses polling: default external interval 2 s versus refresh interval 10 s; when external detection is enabled that interval drives polling. Slow reads are not cancelled by ticks; ticks coalesce behind actions. Explicit refresh can supersede reads; mutations reconcile first. Network auto-fetch is deferred to M3.
- Workflow admission is retained before spawn through gate waits, command gaps, cleanup and queued result reconciliation/drop. Owner/operation Drop is nonblocking. Owned child/group/pipes settle on workers. Last-window close awaits acknowledgments/ordered storage flush asynchronously and rechecks concurrent last removal. Daemonizing/escaping helpers and abrupt crashes are not covered.
